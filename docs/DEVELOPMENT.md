# Разработка Whale

## Сборка

Нужны macOS, Go 1.24 или новее и Xray 26.9.9. Go-зависимости закреплены в
`go.mod` и `go.sum`. Сборка не использует Python.

```sh
make build
./whale
./dist/whale --help
```

`make build` создаёт `dist/whale`. Версия берётся из `VERSION` и записывается
в бинарник через `-ldflags`. Встроенное значение при `go build` без Make —
`dev`. Для ядра подходят `.tools/xray`, `WHALE_CORE` или `--core`.
В установленном пакете Xray находится в соседнем `libexec/xray`.

Launcher `./whale` использует профиль `.local/` проекта. Установленный бинарник
использует `~/.config/vctl`; `--home` или `WHALE_HOME` переопределяют путь.
Старые `VCTL_HOME` и `VCTL_CORE` поддерживаются.

## Архитектура

- `cmd/whale` — точка входа.
- `internal/whale/ui.go` — Bubble Tea: меню, формы, подтверждения и результаты.
- `cli.go` — Cobra-команды и проверяемые изменения настроек; UI использует те же команды.
- `profiles.go`, `state.go` — импорт URI/подписок, совместимый формат профиля,
  атомарная запись и блокировки.
- `config.go`, `data.go` — Xray-конфигурация, правила, пресеты, GeoIP/GeoSite.
- `runtime.go` — Xray, проверки серверов, IPC, автообновление и откат конфигурации.
- `service.go`, `system.go` — macOS launchd, DNS и аварийное восстановление.

Клиент и supervisor — один Go-бинарник. Фоновый процесс не вызывает Python.
Xray остаётся отдельным ядром VPN. Текущая системная реализация предназначена
для macOS; готовая поддержка Windows в этой версии не заявляется.

UI не запускается при перенаправленном stdin: для скриптов используются
подкоманды. Запросы sudo используют скрытое поле ввода внутри панели; интерфейс
остаётся на экране с индикатором выполнения. Выход из UI не посылает команде VPN сигнал остановки.
Обычные операции выполняются асинхронно; Ctrl+C отменяет текущую операцию.
Операции жизненного цикла TUN не прерываются из UI, чтобы не нарушить откат.

Выбор сервера читается через RoutingService Xray по приватному Unix-сокету
`api.sock`. Supervisor обновляет его каждые три секунды. Для TUN доступная
пользователю сводка `tun-status.json` содержит только PID, время и выбранный
сервер; UI проверяет свежесть и PID службы.

## Совместимость

`state.json` сохраняет формат версии 1. Идентификаторы серверов рассчитываются
так же, как в прежнем клиенте. Порядок подписок и пресетов сохраняется при
чтении и записи: он влияет на резервный сервер и приоритет правил.
Служба сохраняет имя `io.github.nagraver.vctl.<UID>.<PROFILE_HASH>` и каталог
`/Library/Application Support/vctl/`. Новый CLI может прочитать состояние и
остановить старый supervisor через прежний Unix-сокет.

`whale tun restart` проверяет новую конфигурацию и соединение до остановки,
затем устанавливает защищённую копию Go-бинарника и Xray. Если новая служба
не запускается, восстанавливается прежний plist и его исполняемый файл.
Не удаляйте старую Python-зависимость, пока переход со старой службы не завершён.

Прежняя Python-реализация доступна в истории Git (тег `v0.4.0`).
Синтетический эталон `internal/whale/testdata/legacy.json`
позволяет сравнивать ID и полные конфигурации прежней и новой реализации,
не используя пользовательские подписки или ключи.

## Проверки

```sh
make test
make integration
```

Первый набор проверяет импорт, идентификаторы, порядок правил, формы,
автодополнение, профиль и определение службы; запускает race detector и `go vet`.
Интеграционный набор поднимает отдельный локальный прокси Xray: проверяет
HTTP-запрос, перезапуск с сохранением порта, отсутствие переподключения из-за
одних временных меток и остановку. Он не меняет системные маршруты и DNS.

Полную проверку TUN нужно выполнять отдельно, когда допустим временный
перерыв связи. Успех локальных тестов не заменяет проверку реального TUN,
восстановления DNS, сна macOS и аварийного завершения.

## Выпуск

1. Установите релизную версию в `VERSION`, выполните проверки и зафиксируйте код.
2. Создайте тег `v<версия>` на коммите приложения и опубликуйте коммит с тегом.
3. Обновите `version` и полный SHA `revision` в `Formula/whale.rb`.
   SHA должен указывать на опубликованный коммит, уже содержащий Go-клиент.
4. Проверьте установку и `brew test`, затем опубликуйте изменение формулы.

Версия в формуле должна совпадать с `VERSION` на указанном коммите.
Само редактирование формулы не меняет установленный через Brew клиент.

Homebrew собирает Whale через Go, устанавливает Xray с проверкой SHA-256,
только команду `whale` и дополнения zsh/bash/fish.
Python не является зависимостью нового пакета.
`formula_renames.json` задаёт переход пакета `vctl` → `whale` по
[правилам Homebrew](https://docs.brew.sh/Rename-A-Formula).

Для остановки VPN перед обновлением используйте `whale tun down`.
Перед удалением пакета выполните `whale tun uninstall`: служба хранится
вне Cellar и не удаляется простым `brew uninstall`.

Язык UI хранится в `state.json` как `ui.language` (`en` / `ru`), по умолчанию `en`.
Изменение этого поля исключается из сравнения настроек соединения supervisor.
Тумблеры TUN и Proxy независимы; неизвестное состояние запрещает переключение
до успешного обновления статуса.
