# 🐋 Whale

**Нативный VPN-клиент для macOS: логика и CLI на Rust, интерфейс SwiftUI, сетевой движок Xray.**

Подписки VLESS/Trojan, выбор и проверка серверов, исключения для сайтов и приложений,
пресеты правил, GeoIP/GeoSite и автоматическое обновление — в отдельном окне.
Терминал нужен только для трёх команд: `whale up`, `whale down`, `whale status`.

Версия **0.6.0**: логика переписана на Rust, нативный интерфейс сохранён.
Готовый пакет предназначен для Apple Silicon и macOS 13 или новее.

```sh
brew tap nagraver/vctl https://github.com/nagraver/vctl.git
brew install --formula nagraver/vctl/whale
open "$(brew --prefix nagraver/vctl/whale)/Whale.app"
```

Для обновления установленной версии: `brew update`, затем
`brew upgrade --formula nagraver/vctl/whale`. Полное имя формулы отличает этот
VPN-клиент от одноимённого приложения в Homebrew Cask.

Готовый архив и контрольная сумма доступны в
[релизе 0.6.0](https://github.com/nagraver/vctl/releases/tag/v0.6.0).
Приложение имеет локальную ad-hoc подпись; Developer ID и нотарификация пока не используются.

Для сборки из исходников:

```sh
make app         # Cargo, SwiftUI, локальная ad-hoc подпись
make test        # Rust-тесты, форматирование, clippy
make integration # проверка конфигураций настоящим Xray без запуска TUN
make test-native # совместимость Rust helper со Swift
```

Требуются Rust (rustup), инструменты разработчика macOS и Xray 26.9.9 в `.tools/xray`.
Подробности закрепления версии и контрольной суммы — в [DEVELOPMENT.md](docs/DEVELOPMENT.md).

## 🚀 Начало работы

Откройте **Whale.app**. В **Servers → Add subscription** вставьте ссылку.
Имя берётся из подписки автоматически, если поле Name оставлено пустым.
Затем откройте **Connection** и нажмите **Connect**.

При первой настройке или замене прежнего Go-помощника macOS запросит права
администратора для установки системного помощника. Обновление останавливает прежний
туннель; затем подключение и отключение работают без повторного ввода пароля,
в том числе после перезагрузки Mac.
Whale не принимает и не сохраняет пароль в собственных формах.
Существующий профиль `~/.config/vctl` подхватывается автоматически.

- **System VPN** направляет системный трафик через туннель с учётом правил.
- **Servers** объединяет подписки и серверы: раскройте подписку, чтобы выбрать сервер.
  **Ping** проверяет отдельный сервер или всю подписку, **Ping all** — все серверы.
  Результаты появляются в таблице по мере готовности; **Stop** останавливает проверку.
  TCP-пинг проверяет доступность порта сервера, но не авторизацию и работу VPN целиком.
  В заголовке подписки также доступны обновление и удаление.

Операции выполняются в фоне, окно остаётся доступным и показывает ход работы.
Закрытие окна или выход из Whale не отключает VPN: службой управляет macOS.
Для остановки нажмите **Disconnect** или выполните `whale down`.
Интерфейс этой версии — на английском.

## ⌨️ Терминал

```sh
whale up       # подключить системный VPN
whale down     # отключить системный VPN
whale status   # показать состояние VPN
```

Если помощник ещё не установлен, первая команда `up` или `down` запросит sudo
для его установки. Последующие вызовы работают без sudo; `status` всегда доступен
без повышения прав.
Запуск `whale` без команды показывает справку. Все настройки меняются в приложении.
`--home /path/to/profile` или переменная `WHALE_HOME` задают другой профиль.
Чтобы GUI и CLI управляли одним соединением, они должны использовать один профиль.

## 🔀 Правила маршрутизации

Откройте **Routing**. По умолчанию весь трафик идёт через VPN;
правила с действием **direct** создают исключения. Можно выбрать обратный режим:
прямое соединение по умолчанию и VPN только для подходящих правил.

| Тип | Пример | Что сопоставляется |
|---|---|---|
| `suffix` | `example.org` | Домен и все его поддомены |
| `domain` | `api.example.org` | Точный домен |
| `cidr` | `192.168.0.0/16` | IP-подсеть |
| `geoip` | `ru` | Категория из geoip.dat |
| `geosite` | `category-ads-all` | Категория из geosite.dat |
| `process` | `dota2` | Имя исполняемого процесса |
| `path` | `/Applications/Example.app` | Путь приложения или исполняемого файла |

Действия: **direct** — напрямую, **proxy** — через VPN, **block** — блокировать.
Правила проверяются по порядку; используется первое совпадение.
Правила для приложений работают в системном TUN. Внутренние процессы приложения
могут иметь другие имена; путь `.app` удобнее для пакета целиком.

Сайт часто загружает изображения и скрипты с других доменов. Для полного обхода
VPN эти домены тоже должны попадать в исключения. Собственный DNS-over-HTTPS
браузера может мешать сопоставлению доменов; при диагностике отключите его.

## 📚 Пресеты и DNS

**Presets** — наборы правил из локального файла, HTTPS-ссылки или встроенного
источника `builtin:lan` / `builtin:ads`. Их можно обновлять, включать и отключать.
Формат пользовательских пресетов описан в [документации разработки](docs/DEVELOPMENT.md).

Для правил GeoIP/GeoSite скачайте базы в **Settings → Update databases**.
Источники и интервал обновления меняются через **Configure sources**.

В **DNS** задаются отдельные HTTPS-резолверы для прямого и VPN-трафика,
а также выбор IPv4/IPv6. Адрес резолвера должен содержать IP, например
`https://1.1.1.1/dns-query`. После отключения туннеля прежний системный DNS восстанавливается.

Изменения сохраняются в профиле после проверки конфигурации Xray. Служба отслеживает
изменения и применяет их с проверкой подключения; при ошибке пытается вернуть
предыдущую рабочую конфигурацию и показывает результат. Сохранённый выбор сервера
и фактически применённое соединение отображаются отдельно. Ошибка чтения статуса
помечает данные как устаревшие.
Автообновление источников выполняет отдельный процесс с правами владельца профиля;
скачивание не удерживает блокировку профиля и не блокирует применение других настроек.

## ⚙️ Хранение и диагностика

- Профиль: `~/.config/vctl/state.json` (старое имя каталога сохраняется для совместимости).
- Системная служба: Rust-контроллер LaunchDaemon, отдельный от GUI и терминала.
- Защищённая копия помощника и ядра: `/Library/Application Support/vctl/`.
- Служебные файлы, журнал состояния и восстановления DNS: `…/runtime/<uid>-<profile-hash>/`
  внутри защищённого каталога службы; доступ ограничен root.
- Сокеты управления: `/Library/Application Support/vctl/sockets/`, проверка UID обеих сторон
  и версии протокола. Новая служба не пишет в пользовательский каталог `tun`.

Профиль содержит секретные ссылки и ключи. Не публикуйте его вместе с журналами.
В **Settings** можно открыть папку профиля, установить или удалить службу.
**Recover DNS** предназначен для восстановления сети после аварийной остановки;
он недоступен, пока VPN работает.

Перед удалением приложения отключите VPN и выберите **Uninstall service** — это удалит также системного помощника.
Профиль при этом сохраняется. Сборка и устройство проекта — в
[DEVELOPMENT.md](docs/DEVELOPMENT.md).

Переустановка или обновление самого привилегированного помощника может снова
потребовать подтверждения администратора. Пароль нигде не хранится.

В этой версии нет kill switch: при остановке или аварии туннеля обычный сетевой
доступ может восстановиться. TCP-пинг и успешные автоматические тесты сами по себе
не доказывают отсутствие утечек трафика; системная проверка описана в документации разработки.
